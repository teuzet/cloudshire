# alignment-judge (Судья соответствия)

Оценщик. Сравнивает слова игрока с ключом фронта.

- **Вход:** ситуация, ходы ключа, предложение (стратегия, атомарное дело или новый объект по соседству).
- **Выход:** `spot_on` (совпало с ходом, КПД ×1,5), `fits` (разумно, ×1), `off` (мимо, ×0,5).
- **Правило:** вердикт хранится в поручении, поэтому одни и те же слова всегда стоят одинаково. Без ключа вердикт `fits` без вызова модели.
- **При поломке:** `fits`.
