# condition-judge (Сверщик условия)

Оценщик. Одно условие поручения, свежие события, ответ «да» или «нет».

- **Вход:** условие словами покровителя («если бунтовщики пойдут на склады») и записи хроники о том, за чем условие следит. Описаний самих дел сверщик не видит: описание беды говорит, чем она грозит, и на живом прогоне сверщик принимал угрозу за случившееся.
- **Выход:** `met` и короткая причина.
- **Когда зовут:** проход жреца (`flows/steward.ts`), когда у поручения с условием накопились события. Какие события его касаются, решает код (`core/world/conditions.ts`): веха или конец отслеживаемого дела, перемена его участника, новая беда рядом. Без отслеживаемого слушаются только новые беды.
- **При поломке:** `false`, поручение ждёт следующего события.
