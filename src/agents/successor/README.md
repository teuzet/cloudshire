# successor

Преемник на должности верховного жреца или сановника, когда прежнего человека не стало.

- Вход: город, бриф, должность и чем она ведает, предшественник и что с ним случилось, пул имён.
- Выход: имя из пула (пол из пула), нрав в два предложения, строка хроники о том, как он занял место.
- Креативный агент: примеров в промпте нет.
- Сломался агент — поток берёт первое имя из пула и короткий нрав без подробностей.
