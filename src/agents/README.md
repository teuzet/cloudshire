# Агенты

Каждый агент — папка: `prompt.md` (инструкция), `schema.ts` (zod-схема ответа), `run.ts`
(сборка промпта, проверка смысла, функция для потоков), `README.md` (вход, выход, что при поломке).
Агенты не импортируют друг друга. Общее — в `_shared`: канон мира (`canon/*.md`), формат сущностей
в промпте, рантайм (`runStructured`, `runToolLoop`), разбор `config/agents.yaml`.

Узкие агенты системы фронтов (от will-interpreter до chronicler) ничего не знают об игре: промпт
описывает только их задачу словами без названий механик. У оценщиков в промпте есть размеченные
примеры, у генеративных агентов примеров нет, требования записаны положительными критериями.
Это проверяет `tests/agents/front-agents.test.ts`. Кто на каком этапе зовётся — `docs/design/fronts.md`.

Модели — в `config/agents.yaml` (`провайдер:модель`). В тестах — `FakeLlm` из `src/adapters/llm/fake.ts`.
Настоящие модели запускаются только по просьбе Ника.
