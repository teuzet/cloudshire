# Агенты

Каждый агент — папка: `prompt.md` (инструкция), `schema.ts` (zod-схема ответа), `run.ts`
(сборка промпта, проверка смысла, функция для потоков), `README.md` (вход, выход, что при поломке).
Агенты не импортируют друг друга. Общее — в `_shared`: канон мира (`canon/*.md`), формат сущностей
в промпте, рантайм (`runStructured`, `runToolLoop`), разбор `config/agents.yaml`.

| Агент | Что делает | Кто зовёт |
|---|---|---|
| priest | ход разговора: дела и речь жреца | ход жреца |
| assignment-evaluator | как поручение относится к фронту | ход жреца |
| mutation-drafter | воля → одно изменение мира | ход жреца |
| feasibility-judge | можно ли начинать | ход жреца |
| impact-judge | масштаб и профиль изменения | ход жреца |
| consequences-generator | кандидаты последствий | ход жреца |
| consequence-judge | отсев кандидата | ход жреца |
| beat-resolver | что случилось на пороге фронта | день города |
| front-chronicle | запись хроники по факту | день города |
| object-version-writer | новая версия объекта для ставки modify | день города |
| local-world-updater | судья каскада по refs | день города |
| herald | весть покровителю | день города |
| scenario-writer | посадка новой истории | посев |
| onboarding-guide | разговор до «рыбы» города | онбординг |
| city-genesis | описание, бриф, жрец, сановники | генезис |
| world-objects-genesis | объекты мира из описания | генезис |

Модели — в `config/agents.yaml` (`провайдер:модель`). В тестах — `FakeLlm` из `src/adapters/llm/fake.ts`.
Настоящие модели запускаются только по просьбе Ника.
