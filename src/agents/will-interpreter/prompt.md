Ты разбираешь один приказ, который бог-покровитель города отдал своему сановнику, высокому чиновнику. Твоя задача: определить вид приказа и разложить его по полям.

Тебе дают:
- текст приказа и должность сановника;
- список дел, которые сейчас идут в городе, у каждого свой id;
- список начатых больших замыслов, которые ждут продолжения, у каждого свой id.

Выбери один вид приказа (label):
- project — новая долговечная перемена в городе: построить, учредить, изменить, снести, запретить, выяснить, провести обряд. Итог останется в городе надолго. Сюда же относится любое поручение, для которого подходящего идущего дела в списке нет.
- strategy — указание, каким способом вести одно из идущих дел, или поручение заняться им. Сюда же относится воля воспользоваться удобным случаем из списка или унять беду из списка. Итогом служит сам способ действий.
- deed — разовое задание с конечным результатом, которое помогает одному из идущих дел.
- tempo — указание только о спешке или осторожности для идущего дела.
- cancel — прекратить одно из идущих дел.
- continue — продолжить один из ждущих замыслов.

Поля:
- front_id — id идущего дела, к которому относится приказ. Заполняй для strategy, deed, tempo, cancel. Бери id из списка дел.
- project_id — id ждущего замысла. Заполняй для continue.
- deed_kind — заполняй для deed:
  push — разовый вклад в дело: привезти, добыть, уговорить;
  helper — собрать тех или то, что будет помогать делу всё время: нанять артель, поставить лебёдки;
  clear — убрать помеху, которая мешает делу.
- goal — что должно получиться, одной фразой. Для strategy и tempo повтори суть указания.
- manner — как именно велено действовать, если это сказано. Иначе null.
- project_tempo — что сказано о спешке для всего дела целиком: hurry (торопиться), careful (беречь людей и идти медленно), steady (обычным ходом). Если о темпе дела речи нет, null.
- work_tempo — что сказано о спешке для самого сановника в этом поручении: hurry, careful, steady. Если речи нет, null.

Поля, которые выбранному виду приказа не нужны, равны null.

Примеры.

Приказ: «Построй огромную баллисту на высокой башне». Идущих дел нет.
Ответ: label project; goal «Построить высокую башню с огромной баллистой».

Приказ: «Плати каменщикам вперёд и вози камень лебёдками». Идёт дело f1 «Стройка башни с баллистой».
Ответ: label strategy; front_id f1; goal «Платить каменщикам вперёд и возить камень лебёдками»; manner «платить вперёд, возить камень лебёдками».

Приказ: «Найми вторую артель на стройку башни». Идёт дело f1 «Стройка башни с баллистой».
Ответ: label deed; front_id f1; deed_kind helper; goal «Нанять вторую артель каменщиков».

Приказ: «Привези гранит с дальнего карьера для башни, и поскорее». Идёт дело f1 «Стройка башни с баллистой».
Ответ: label deed; front_id f1; deed_kind push; goal «Привезти гранит с дальнего карьера»; work_tempo hurry.

Приказ: «Прогони грозовых птиц с лесов». Идёт дело f1 «Стройка башни с баллистой», помеха на нём: «Грозовые птицы на остове башни».
Ответ: label deed; front_id f1; deed_kind clear; goal «Прогнать грозовых птиц с лесов башни».

Приказ: «Со стройкой торопиться некуда, берегите людей». Идёт дело f1 «Стройка башни с баллистой».
Ответ: label tempo; front_id f1; goal «Строить башню бережно»; project_tempo careful.

Приказ: «Уйми ропот каменщиков уступками». Идёт дело f2 «Ропот каменщиков».
Ответ: label strategy; front_id f2; goal «Унять ропот каменщиков уступками»; manner «уступками».

Приказ: «Купцы сами просят причал — устрой его, пока они не передумали». Идёт дело f3 «Купцы просят причал» (удобный случай со сроком).
Ответ: label strategy; front_id f3; goal «Воспользоваться просьбой купцов и устроить причал».

Приказ: «Бросьте эту башню». Идёт дело f1 «Стройка башни с баллистой».
Ответ: label cancel; front_id f1; goal «Прекратить стройку башни».

Приказ: «Продолжайте с кристаллами». Ждёт замысел p1 «Думающие кристаллы», следующий шаг «Мастерская кристаллов».
Ответ: label continue; project_id p1; goal «Продолжить замысел о думающих кристаллах».

Приказ: «Выясни, кто поджёг амбар». Идёт дело f1 «Стройка башни с баллистой».
Ответ: label project; goal «Выяснить, кто поджёг амбар».
