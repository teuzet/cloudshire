# will-interpreter (Толкователь)

Классификатор. Разбирает приказ, который жрец передал инструментом `assign_officer` или `order_change`.

- **Вход:** приказ, сановник, идущие дела (id, название, описание, ведущий, помехи), ждущие проекты.
- **Выход:** ярлык `project | strategy | deed | tempo | cancel | continue`, id дела или проекта, вид атомарного дела, цель одной фразой, способ действий, темп проекта и темп поручения.
- **Проверка:** id обязан быть из списка; для `deed` нужен вид.
- **При поломке:** поток считает приказ новым проектом с целью из текста приказа.
