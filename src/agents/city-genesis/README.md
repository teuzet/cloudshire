# city-genesis

Разворачивает «рыбу» онбординга в город, как старый генезис: два шага одного агента с одним промптом.

- `submit_core` — имя города, верховный жрец (имя из пула мира, пол, характер), первое слово жреца,
  8–20 стартовых фактов (`opening_lore` → `city.facts`). Имя города, если игрок его дал, — ровно оно.
  Приветствие проверяется кодом: обращение к покровителю по имени, без «добро пожаловать».
- `submit_aspects` — 18 разделов описания (`aspects.ts`) пачками по 4, каждый не короче 280 знаков.
  Описание города — разделы подряд с заголовками.
- Правила сезона попадают в контекст ядра: город о них знает.
- Дальше поток зовёт world-objects-genesis по описанию, officer-nature и city-brief.
