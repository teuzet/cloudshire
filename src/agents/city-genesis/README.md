# city-genesis

Первый шаг генезиса: портрет города из питча (`submit_portrait`).

- Вход: «рыба» онбординга (питч, имя города, покровитель), пул имён, правила сезона.
- Выход: портрет (свободная проза 2500–6000 знаков), `hidden` (чего горожане не знают: правда за
  загадками и природа опасностей), имя города (ровно данное игроком, если дано), верховный жрец.
- В портрете есть две-четыре большие нерешённые вещи: загадка, медленная опасность, обещание.
  Из них world-objects-genesis делает объекты с пометкой `arc`.
- Портрет хранится в `city.description`; агентам после генезиса идёт бриф.
- Креативный агент: примеров в промпте нет, требования записаны положительными критериями.
