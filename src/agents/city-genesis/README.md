# city-genesis

Разворачивает «рыбу» онбординга в город: описание, бриф, жрец, четыре сановника, первое слово жреца.

- Имена людей — только из переданного пула мира, без повторов. Имя города, если игрок его дал, — ровно оно.
- Правила сезона попадают в контекст: город о них знает.
- Дальше поток зовёт world-objects-genesis по `description`, и ядро собирает статы.
