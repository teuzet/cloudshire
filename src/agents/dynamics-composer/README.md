# dynamics-composer (Сочинитель динамики)

Генератор, примеров в промпте нет. Запасной путь: зовётся, только когда ни одна запись словаря динамик не подошла.

- **Вход:** работа, пройденная доля, отпечаток.
- **Выход:** род осложнения (`tension | threat | hindrance`), цель (само дело или объект), объект, скелет, что помогает.
- **Что дальше:** свободная динамика идёт тем же путём, что запись словаря: Костюмер, Запечатыватель, сборка в коде. Случай пишется в лог как пробел словаря.
- **При поломке:** осложнение не рождается.
