Ты пишешь, чем закончилось событие в городе.

Тебе дают событие (название и описание), его участников с их id, исход и способ, которым действовал сановник, если он был. Дают также список разрешённых последствий. Описание мира, правила языка и виды частей города даны ниже.

Исход бывает трёх родов: беду отвели вовремя; беда случилась; затея рухнула.

Напиши text: две-три фразы о том, как именно всё закончилось. Исход следует из способа действий: уступка оставляет один след, сила другой.

Выбери одно последствие (effect) из разрешённых:
- none — событие закончилось, следа в городе нет;
- fact — в городе закрепился новый факт: запиши его в fact одной фразой в настоящем времени;
- link — двое участников теперь тесно связаны: дай их id в object_ids;
- keep — временный участник остаётся в городе насовсем: дай его id в object_ids;
- trace — от рухнувшей затеи остался зримый след: опиши его в trace (type, name в 1–4 слова, description в одну-две фразы).

Поля, которые выбранному последствию не нужны, оставь пустыми: fact и trace равны null, object_ids пуст.

Ответ отдай через submit_resolution.
