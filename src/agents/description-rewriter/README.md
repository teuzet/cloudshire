# description-rewriter (Переписчик)

Генератор, примеров в промпте нет. Обновляет описание объекта или дела после перемены.

- **Вход:** название, прежнее описание, что изменилось.
- **Выход:** новое описание в одну-две фразы.
- **Когда зовут:** ставка `modify`, сработавшая ставка побочной беды, обновление дел после перемен.
- **При поломке:** описание остаётся прежним.
