# assignment-evaluator

Как поручение сановника относится к одному фронту.

- Вход: фронт (описание, скрытая логика, живые события), сановник, текст поручения.
- Выход: `AssignmentVerdict` — direction, efficiency, blocks, stopWhen.
- Проверка смысла: blocks только из живых событий этого фронта.
- Кто зовёт: поток хода жреца, по разу на каждый фронт-кандидат (`fronts.assignment.evaluatorCandidates`).
- Если агент сломался: поток ставит поручение без фронта (`NO_EFFECT`).
