# city-brief

Компактный фактический бриф города (до 3500 знаков) и канонические неизвестности. Промпт — старый cityBrief.

- Бриф идёт всем агентам как «описание города»; полное описание из аспектов хранится в `city.description`.
- Каждая неизвестность привязана к объектам острова (`object_ids`). Эти объекты закрыты для посадок
  историй, пока тайна не раскрыта: проверяет scenario-writer. Сам «выстрел» тайны пока не написан.
- Сломался агент — поток берёт начало описания как бриф и пустой список неизвестностей.
