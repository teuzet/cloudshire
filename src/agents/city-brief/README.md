# city-brief

Бриф города: неизменное (природа острова, давний уклад, прошлое, вера, тон), 1500–2000 знаков,
и канонические неизвестности. Пишется после объектов, по портрету и списку объектов.

- Изменяемое живёт в объектах, поэтому бриф после генезиса не правится. Код отклоняет бриф, который
  называет людей или объекты с собственными именами, и просит сказать общими словами.
- Бриф идёт всем агентам как «описание города»; портрет хранится в `city.description`.
- Каждая неизвестность привязана к объектам острова (`object_ids`): эти объекты закрыты для посадок
  историй, пока тайна не раскрыта.
- Сломался агент — поток берёт начало портрета как бриф и пустой список неизвестностей.
