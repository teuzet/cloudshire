# pitch-auditor

Сверщик генезиса: перечисляет детали питча и для каждой говорит, где она в городе — объект (имя ровно
как в списке), `brief` или `missing`. Пропавшие поток отдаёт world-objects-genesis на добор.

- Судья: в промпте много размеченных примеров.
- Сломался агент — поток считает, что пропавших нет, и идёт дальше.
