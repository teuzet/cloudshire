# onboarding-guide

Клерк онбординга: разговор с игроком до питча города и имён (`CitySeed`) для генезиса.

- Вход: весь разговор (`OnboardingDraft.messages`), питч, который игрок уже видел, настроения для набросков
  и вопросы на выбор. Настроения и вопросы поток берёт из книги клерка `book.yaml` (`core/clerk.ts`):
  три настроения из разных семей; первый вопрос случайный, дальше шорт-лист незаданных с упором на темы,
  которые ещё не звучали.
- Выход: реплика игроку, текущий текст питча, известные имена, готовность, номер заданного вопроса,
  отметка о показанных набросках, прозвучавшие темы.
- Питч — свободный текст без полей. Его показывает система отдельно от реплики; правок сколько угодно.
- Готовность проверяет код: игрок видел именно этот текст питча и назвал покровителя. Иначе клерк получает
  замечание и отвечает заново.
- Один открытый вход и три пути по ответу игрока: знает, чего хочет; просит выбрать за него (три наброска);
  затрудняется описать (вопросы из книги).
- Говорит с игроком напрямую, поэтому в system есть контракт безопасности.
- В промпте нет примеров городов и вопросов: книга приходит данными в запросе.
- Проба вживую без генезиса: `npm run clerk -- <имя прогона> <реплика игрока>`.
