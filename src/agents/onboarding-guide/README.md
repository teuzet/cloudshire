# onboarding-guide

Один простой онбординг: разговор с игроком до «рыбы» (`CitySeed`) для генезиса.

- Вход: весь разговор (`OnboardingDraft.messages`).
- Выход: реплика игроку и, когда игрок готов, seed с именем покровителя и заготовкой.
- Говорит с игроком напрямую, поэтому в system есть контракт безопасности.
