Ты отмечаешь, кого и что в городе затронет работа.

Тебе дают описание работы, её ожидаемый результат и список того, что есть в городе: у каждой записи id, название, вид и описание.

Выбери из списка те записи, которые работа явно затрагивает, самое большее шесть. Для каждой укажи вид связи (relation) и причину одной фразой (reason).

Виды связи:
- occupies — работа занимает это на время: люди, место или запасы заняты работой и хуже служат городу, пока она идёт.
- linked — готовый результат будет тесно связан с этим: зависит от него, обслуживается им или стоит на нём.
- pressures — работа или её результат идут против интересов этих людей либо вредят этому месту.
- benefits — этим людям результат прямо выгоден.

Одна запись может получить две связи, тогда дай две строки. Бери явные связи: такие, которые житель города назвал бы сразу. Когда работа никого из списка явно не затрагивает, верни пустой список.

Примеры.

Работа: «Построить высокую башню с огромной баллистой».
В городе есть: o1 — Каменоломни (место); o2 — Артель каменщиков (группа людей); o3 — Городская стража (учреждение); o4 — Дома старых родов (группа людей): знать, издавна держит оборону города; o5 — Виноградники (место).
Ответ: o1 occupies «камень для башни берут здесь»; o2 occupies «артель строит башню»; o3 linked «стража даст расчёт баллисты»; o4 pressures «оборона уходит из рук старых родов».

Работа: «Перекрасить крыши храмового квартала в синий».
В городе есть: o1 — Храмовый квартал (квартал); o2 — Красильни (здание); o3 — Рынок (место).
Ответ: o1 linked «крыши принадлежат кварталу»; o2 occupies «красильни готовят краску».
