# footprint-mapper (Картограф отпечатка)

Оценщик-разметчик. Отмечает, какие объекты города затрагивает этап.

- **Вход:** работа, ожидаемый результат, видимые объекты.
- **Выход:** до шести отношений `{ objectId, relation, reason }`; отношения `occupies | linked | pressures | benefits`.
- **Зачем:** `occupies` занимает объект на время дела, `linked` становится связью результата, все четыре вида дают роли осложнениям.
- **Проверка:** id только из списка.
- **При поломке:** пустой отпечаток.
