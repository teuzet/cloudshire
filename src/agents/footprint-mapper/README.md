# footprint-mapper (Картограф отпечатка)

Оценщик-разметчик. Отмечает, какие объекты города затрагивает этап.

- **Вход:** работа, ожидаемый результат, видимые объекты.
- **Выход:** до шести отношений `{ objectId, relation, reason }`; отношения `occupies | linked | pressures | benefits | helps | hinders`.
- **Зачем:** `occupies` занимает объект на время дела, `linked` становится связью результата, `helps` и `hinders` (стоящее рядом облегчает или затрудняет работу) держат дело, пока оно идёт: быстрее или медленнее, вместе не больше `fronts.hold.foundCap` от скорости ведущего. Все виды дают роли осложнениям.
- **Проверка:** id только из списка.
- **При поломке:** пустой отпечаток.
