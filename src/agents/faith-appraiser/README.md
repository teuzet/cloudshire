# faith-appraiser (Оценщик веры)

Оценщик. Выбирает случай и силу события для веры. Число даёт код по таблице `faith.impulses`.

- **Вход:** текст события, чья была воля, похожие недавние события.
- **Выход:** случай `harm_willed | harm_unguarded | harm_averted | boon_willed | none` и сила `minor | notable | grave | shock`.
- **Когда зовут:** завершение дела, конец угрозы, авария, крах недостижимого дела.
- **При поломке:** вера не меняется.
