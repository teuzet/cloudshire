# key-sealer (Запечатыватель)

Генератор, примеров в промпте нет. Пишет скрытый ключ фронта: ходы, которые двигают его в нужную сторону.

- **Вход:** название и описание ситуации, её род (работа, недовольство, беда со сроком, удобный случай, поиск), участники, подсказка из записи словаря, нужен ли подвох исхода.
- **Выход:** от 3 до 5 ходов; подвох, если код бросил исход «с подвохом».
- **Кто видит:** лормастер и Судья соответствия. Жрец и игрок ключа не видят.
- **Когда зовут:** рождение фронта проекта, осложнения и эха; обновление после перемен.
- **При поломке:** фронт живёт без ключа, любая стратегия получает «годится».
