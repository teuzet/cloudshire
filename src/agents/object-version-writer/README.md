# object-version-writer

Пишет новую версию объекта, когда ставка фронта — `modify` без готовой версии.

- Вход: правила, объект с версиями, что изменилось.
- Выход: `VersionDraft` (описание, вес, относительный профиль). Вклад в статы считает ядро.
- Агент сломался — поток закрывает фронт как invalid, мир не трогает.
