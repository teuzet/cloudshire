# costumer (Костюмер)

Генератор, примеров в промпте нет. Одевает абстрактный скелет в конкретику города.

- **Вход:** скелет (запись словаря динамик или свободная динамика), род события, причина, объект в роли, темы города, имена из пула, нужен ли новый объект.
- **Выход:** название, описание, слух для жреца, прорыв (что будет без вмешательства), новый объект (помеха, находка, скрытый виновник).
- **Когда зовут:** каждое осложнение и каждый шаг эха.
- **При поломке:** осложнение не рождается, бросок считается пустым.
