# existence-judge (Привратник канона)

Оценщик. Есть ли в городе то, что назвал покровитель.

- **Вход:** предмет, слова приказа, части города, известные факты, описание мира.
- **Выход:** `exists` (с id части, если есть), `invent` (подробность без пользы сама по себе: её дописывает лормастер фактом), `unknown` (вещь с ценностью: её можно только найти проектом), `absent` (противоречит миру).
- **Когда зовут:** жрец, встретив в приказе незнакомое, вызывает тул `check_existence`.
- **При поломке:** `unknown`: жрец не выдумывает и не отказывает, а предлагает поиск.
