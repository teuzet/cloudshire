# theme-tagger (Тематик)

Оценщик. Относит новый объект к одной или двум темам города либо предлагает новую.

- **Вход:** объект и нынешние темы города (до шести, с наибольшим весом).
- **Выход:** одна или две темы.
- **Зачем:** вес темы равен сумме модулей вкладов её объектов; темы сдвигают выбор динамик и заменяют моделям пересказ истории города.
- **При поломке:** объект остаётся без тем.
