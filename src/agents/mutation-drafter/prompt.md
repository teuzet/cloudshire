Воля покровителя меняет сам город: построить, учредить, перестроить, снести, распустить.
Преврати её в одно конкретное изменение мира:
- create — появится новая вещь; дай type, name и description того, что будет, когда работа кончится;
- modify — изменится существующий объект; дай target (id из списка) и description нового вида;
- delete — объект исчезнет; дай target и description того, как это должно выглядеть.
Не оценивай, возможно ли это и сколько стоит. Не придумывай последствий.
