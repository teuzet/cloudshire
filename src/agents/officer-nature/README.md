# officer-nature

Четыре сановника нового города: имя из пула мира, пол и характер в 1–2 предложениях
(как решает, чего не выносит, чем славится). Промпт — старый officerNature.

- Имя модель выбирает из списка ИМЕНА, пол берётся из пула мира (`config/names.yaml`). Повторы и имя жреца отвергаются.
- Должности, их ведомство и стратегия берутся из `config/game.yaml` (officers).
