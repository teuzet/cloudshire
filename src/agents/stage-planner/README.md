# stage-planner (Разбивщик)

Генератор, примеров в промпте нет. Раскладывает одобренную цель на цепочку этапов.

- **Вход:** цель, слова приказа (только если страж не поправлял цель), нехватки от Стража канона, видимые объекты.
- **Выход:** от 1 до 4 этапов. У этапа: название, работа, результат (`new_object | change_object | remove_object | restore_object | move_object | fact`, вид, имя, описание, родитель; для переноса родитель — куда переносят), место работ, известен ли исход заранее.
- **Проверка:** id существующих объектов обязаны быть из списка; у нового объекта есть вид; объект не переносят в самого себя.
- **Кто ещё зовёт:** атомарное дело вида `helper`, чтобы назвать помощника.
- **При поломке:** проект не открывается, жрец просит сказать иначе.
