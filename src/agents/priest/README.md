# priest

Ход разговора: реплика покровителя → вызовы дел → речь жреца.

- Вход: правила, город, день, реплика (и цитата, если это ответ на сообщение).
- Тулы: `assign_officer`, `order_change`, `withdraw_assignment`, `write_note`; итоговый — `submit_reply`.
- Обработчики тулов даёт поток хода жреца (шаг 3): там поручение садится на фронт
  (assignment-evaluator), воля проходит цепочку mutation-drafter → … → фронт стройки.
- `acted` — было ли действие с делом; от этого зависит цена хода в мане.
- Скрытая логика фронтов, события и улики жрецу не видны: только описания идущего.
