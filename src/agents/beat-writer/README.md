# beat-writer (Агент битов)

Генератор, примеров в промпте нет. Пишет суть вехи.

- **Вход:** дело, пройденная доля, ведущий и его стратегия, будущий результат, сведение для раскрытия, разрешённые кодом эффекты.
- **Выход:** текст в 2–3 фразы и эффект `none | reveal`.
- **Что дальше:** веха без перемен попадает в хронику этим текстом; при переменах текст уходит Летописцу как суть события.
- **При поломке:** в хронику идёт сухая запись от кода («Работа продвинулась»).
