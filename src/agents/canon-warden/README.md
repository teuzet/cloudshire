# canon-warden (Страж канона)

Оценщик. Проверяет, достижима ли цель нового проекта в мире игры.

- **Вход:** цель, факты города, видимые объекты.
- **Выход:** `possible | amended | unattainable`, причина, цель (исходная или с поправкой), до трёх нехваток.
- **Что дальше:** нехватки уходят Разбивщику и становятся первыми этапами. `unattainable` не отказ: игрок получает предупреждение, а повторный приказ запускает дело, которое идёт до краха.
- **При поломке:** цель считается достижимой без нехваток.
