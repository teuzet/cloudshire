# loremaster

Авторитет по фактам мира: отвечает на вопросы о городе и на ходу дописывает канон,
держа его консистентным с хроникой.

- Вход: город, день, вопросы, кто спрашивает, и `frontId` идущей истории, если вопрос о ней.
- Тулы: `read_lore` (обязателен первым), `add_fact`, `update_fact`, `retire_fact`; итоговый — `submit_answers`.
- Факты пишутся прямо в `city.facts` через `core/lore.ts`; сохраняет город поток, который позвал лормастера.
- Факт-незнание («неизвестно», «возможно») ядро отвергает: незнание не факт.
- Канонические неизвестности города (`city.unknowns`) не раскрываются.
- `focusStory` — фронт под фокусом: его скрытый слой (чем кончится, alignment, нераскрытые улики)
  лормастер видит, город нет; наружу из него только косвенное.
- Сопряжение и информатор о соседе пока не перенесены.
