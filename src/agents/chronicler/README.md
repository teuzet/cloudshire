# chronicler (Летописец)

Генератор, примеров в промпте нет. Литературно оформляет «дифф» состояния города.

- **Вход:** суть события (от Агента битов, Развязчика или кода), список перемен словами от `core/world/changes.ts`, игровая дата.
- **Выход:** запись летописи в 2–4 фразы.
- **Правило:** каждое значимое изменение в списке объектов и фронтов сопровождается записью. Веха без перемен идёт в хронику без Летописца.
- **При поломке:** в хронику идёт суть события и перемены строкой.
