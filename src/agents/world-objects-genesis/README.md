# world-objects-genesis

Объекты мира из портрета города (city-genesis), в два вызова:

- `submit_object_list` — список: имя, вид, связи (`links` → `refs`), вложенность (`parent` → `parentId`),
  скрытость (правда из `hidden` портрета), пометка `arc` у двух-четырёх больших нерешённых вещей
  разного рода. Код проверяет число, повторы, связи к несуществующим, объекты без связей, скрытые без
  видимого соседа, число и разнообразие `arc`.
- `submit_object_details` — описание, вес и профиль по статам для каждого объекта списка.
- Добор: те же два вызова с `mustCover` (детали питча, которых не нашёл pitch-auditor) и `existing`.
Статы города из объектов собирает ядро (`genesisStats`). Жрец и сановники в список не входят.
