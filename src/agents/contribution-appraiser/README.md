# contribution-appraiser (Оценщик вклада)

Оценщик. Называет класс вклада объекта по каждому стату со знаком. Чисел не знает: пункты из класса делает `core`.

- **Вход:** предмет (имя, вид, описание), уровни статов словами, самые весомые объекты города с вкладом классами; при переоценке прежний вклад и что случилось.
- **Выход:** до четырёх эффектов `{ stat, direction, size }` и причина.
- **Когда зовут:** старт этапа, помощник, подвох исхода, побочное и плюсовое осложнение, эхо по связям, ставка `modify`.
- **При поломке:** новый объект получает пустой вклад, переоценка оставляет прежний.
