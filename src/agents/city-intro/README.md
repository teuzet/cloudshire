# city-intro

Стартовая сцена после генезиса:
- `view` — вид острова сверху, 600–900 знаков, сообщение системы (в Telegram курсивом);
- `priest_call` — два-четыре коротких сообщения жреца: проверка связи, без ввода в курс дела.

Жрец ликует, когда получает первый ответ покровителя: агент priest видит в блоке хода, что это первое
слово бога. Сломался агент — поток берёт короткий запасной текст и один зов.
