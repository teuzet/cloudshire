# scenario-writer

Сажает историю: подгоняет заготовку из `scenarios/*.yaml` под город или пишет новую по зерну.

- Выход проверяется `scenarioDraftSchema` из ядра (без осей режиссёра: их ставит код), плюс смысл: id уникальны, ссылки и цели ставок
  ведут в историю или в живые объекты города.
- Тайны острова (`city.unknowns` с объектами) закрыты: история, которая ссылается на их объекты
  или ставит на них ставку, отвергается. Тот же запрет держит поток посева для запасной заготовки.
- У адаптированной заготовки id сохраняется, чтобы `scenariosUsed` не дал сыграть её дважды.
- Посадку делает `plantScenario` в ядре.
