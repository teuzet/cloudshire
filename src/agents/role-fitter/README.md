# role-fitter (Примерщик)

Оценщик. Один вопрос, один кандидат, ответ «да» или «нет».

- **Вход:** условие в форме вопроса, описание кандидата, обстоятельства.
- **Выход:** `fits` и короткая причина.
- **Когда зовут:** подбор объекта на роль в записи словаря динамик; ворота обновления после перемен («перемена существенно меняет ход дела?»); сопротивление стороны при названном способе работы («сможет ли эта сторона помешать работе, если вести её так?»).
- **При поломке:** `false`, кандидат в жребий не попадает.
