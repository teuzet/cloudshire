# Потоки

Склеивают ядро и агентов в игровые сценарии. Знают порты (`FlowDeps`), не знают провайдеров и транспорт.
Город меняется в памяти и сохраняется один раз в конце потока; вести уходят после сохранения.
Один писатель на город — `CityLocks`.

| Поток | Что делает |
|---|---|
| `onboarding.ts` | `onboardingMessage` — разговор до «рыбы»; `runGenesis` — город из «рыбы»: портрет → список объектов со связями → описания и статы → сановники → бриф неизменного → сверка с питчем и добор → вид сверху и зов жреца; `resetPlayer` |
| `priest-turn.ts` | `patronMessage` — догнать город, ход жреца, дела, лормастер, мана; сорванный ход откатывается вместе с дописанными фактами |
| `will.ts` | `playerWill` — приказ сановнику: Толкователь относит его к новому проекту, продолжению, стратегии, атомарному делу, темпу или отмене; `withdraw` — снять сановника |
| `day.ts` | `processDue` / `advanceCity` — задания очереди: веха, завершение, срок и месячный бросок фронта, посев |
| `complications.ts` | бросок риска, сборка осложнения из словаря динамик, эхо по связям, обновление дел после перемен |
| `seeding.ts` | `seedStories` / `plantStory` — держит в городе `seeding.activeStories` историй: заготовка или история по зерну; объекты тайн острова не трогает |
| `succession.ts` | `fillOffices` — пустую должность жреца или сановника сразу занимает преемник: объект-человек, запись летописи, весть системы; людей на должностях уносит только крупная история или воля покровителя |
| `fronts.ts` | пересчёт скоростей с постановкой заданий, импульс веры |
| `briefs.ts` | что и какими словами показать узким агентам: вклад классами, сроки полосами |
| `chronicle.ts` | Летописец оформляет перемены события в запись, Вестник делает из неё весть; запись слышат поручения с условием |
| `steward.ts` | `runSteward` — проход жреца: сверка поручений с условием, очередь поручений на потом, наказ на беды без ответа |
| `scheduler.ts` | `runDueCities` — проход по городам с наступившими заданиями |
| `world.ts` | мир: часы, сезон, пул имён; для dev промотка дней и пауза часов |
| `save.ts` | dev: сохранение и загрузка игры игрока; при загрузке игровой день тот же, что при сохранении |

Агент сломался — поток идёт по запасному пути (`tryAgent`) и пишет `agent_failed` в лог.
Сценарные тесты — `tests/flows/*` на `FakeLlm`, памяти и ручных часах.
