# Потоки

Склеивают ядро и агентов в игровые сценарии. Знают порты (`FlowDeps`), не знают провайдеров и транспорт.
Город меняется в памяти и сохраняется один раз в конце потока; вести уходят после сохранения.
Один писатель на город — `CityLocks`.

| Поток | Что делает |
|---|---|
| `onboarding.ts` | `onboardingMessage` — разговор до «рыбы»; `runGenesis` — город из «рыбы»: ядро → аспекты → объекты и статы → сановники → бриф с каноническими неизвестностями; `resetPlayer` |
| `priest-turn.ts` | `patronMessage` — догнать город, ход жреца, дела, лормастер, мана; сорванный ход откатывается вместе с дописанными фактами |
| `day.ts` | `processDue` / `advanceCity` — задания очереди: пороги, ставки, каскад, посев |
| `seeding.ts` | `seedStories` / `plantStory` — держит в городе `seeding.activeStories` историй: заготовка или история по зерну; объекты тайн острова не трогает |
| `fronts.ts` | поручение на фронт, воля игрока как фронт, снятие, пересчёт скоростей |
| `chronicle.ts` | запись хроники и весть жреца |
| `scheduler.ts` | `runDueCities` — проход по городам с наступившими заданиями |
| `world.ts` | мир: часы, сезон, пул имён; промотка дней для dev |

Агент сломался — поток идёт по запасному пути (`tryAgent`) и пишет `agent_failed` в лог.
Сценарные тесты — `tests/flows/*` на `FakeLlm`, памяти и ручных часах.
