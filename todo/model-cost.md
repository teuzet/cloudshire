## Как сейчас разложено

Почти всё игровое — **gpt-5.6-luna**. Дорогие исключения:

| Сцена | Модель | Когда | Заметки |
|--------|--------|--------|---------|
| Генезис core + аспекты | claude-sonnet-4-6 | раз на город | ~5 батчей аспектов (`aspectBatchSize: 4`, ~18 аспектов) + 1–3 попытки ядра |
| `mysteryStart` | terra | каждый посев тайны | до `generateTries: 6` |
| `mysteryJudgeTerra` | terra | после luna-PASS ядра | второй судья с нуля |
| Фабрика аннотаций | sonnet + luna-судья | досев при `!opening` | `poolMin: 10`, стартер уже длиннее → почти всегда skip |
| Остров + 4 портрета | gpt-image-2 medium | раз на город | 1792×1024 + 4×1024; не в usage |
| Жрец, письмо месяца, биты, саспенс, онбординг, концепт | luna | чат / тик / генезис | дёшево за вызов, объём на tickNews и жреце |

Посев тайны, худший случай: селектор (luna) → до 6× terra-ядро → каскад судей (luna, затем terra) → до 3× презентация + судья презентации → ставки.

Жрец: `turnBudgetMs` 120 с. Вложенные luna (ломастер, информатор, `durationJudge`) и второй прогон ради `submit_reply` делят этот бюджет, не terra.

## Что уже не жжёт деньги

- Жрец, письмо месяца, биты, keep, стюард, саспенс-посев — luna.
- Architect удалён (был terra + скрипт).
- Досев пула на тике почти не крутится, пока каталог ≥ `poolMin`.

Резать luna «чтобы сэкономить» почти бесполезно: ставка маленькая, страдает голос.

## Предложения

Нужно явное да/нет. Не делать пачкой без разговора.

### 1. `mysteryStart`: luna, terra только после FAIL

**Влияние: высокое.** Terra — основной расход посева тайны; до 6 попыток.

Риск: слабее причинный граф, больше кругов ревизии. Компромисс: первая попытка luna, terra с второй.

### 2. Не звать `mysteryJudgeTerra`, если luna уже PASS

**Влияние: высокое.** Сейчас дешёвый rejector нашёл PASS — всё равно полный terra-acceptor.

Риск: больше дырявых ядер до презентации. Компромисс: terra только на UNCERTAIN или сэмпл 10–20%.

### 3. Аспекты генезиса на luna (или haiku), Claude только core

**Влияние: высокое.** Исторически аспекты — самый жирный scene в usage.

Риск: стиль longform разъедется с ядром. Компромисс: Claude на core + первый батч аспектов.

### 4. Урезать ретраи тайны: `generateTries` 6→3, `presentationTries` 3→2

**Влияние: среднее.** Меньше пустых дорогих кругов.

Риск: чаще `generation_failed`, дырка на доске. Можно начать отсюда — крутилка в YAML, без смены модели.

### 5. Фабрику аннотаций не звать с тика

**Влияние: сейчас низкое, страховка средняя.** Вызов из посева при `!opening`. Пока стартер ≥ min, skip. Если min поднимут или каталог уедет — sonnet × `refillBatch: 3` посреди тика.

Делать: только `npm run seed-annotations` / suspense. Тик не доливает.

### 6. Логировать image usage

**Влияние: учёт, не экономия.** Пять картинок на город сейчас слепые. Без этого нельзя решить, резать ли качество.

### 7. Картинки `quality: low` или без портретов до хостинга

**Влияние: среднее API $.** UX: портреты столпов и остров. Отдельный проход про хостинг картинок это не отменяет.

### 8. Мелочи (потом)

- Селектор аннотаций эвристикой вместо luna-шортлиста.
- `durationJudge` эвристикой на очевидных сроках («в этом месяце»).
- Не звать `statJudge` / `storyKeep` на совсем пустом месяце.

---

## Не трогать без отдельной причины

- Жрец на luna: большой промпт, маленькая ставка. Урезать canon — про голос, не про счёт.
- Письмо месяца: часто, но luna. Резать частоту — продукт (`set_news_schedule`), не модель.
- Саспенс целиком на luna — ок.
- Пересадка всего генезиса на luna одним махом — риск канона города.

---

## Как мерить после изменений

1. `npm run tokens` по worldId до и после (неделя / N городов).
2. Отдельно посчитать картинки, когда появится запись в usage.
3. Смотреть не только $: доля `generation_failed` на посеве тайны и длина генезиса.
