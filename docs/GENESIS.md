# Генезис города

Один путь: оси → концепт `READY` → `generateDomain`. Старого «300 очков и теги» нет.

Код: `onboarding.js`, `onboardingTools.js`, `genesisAxes.js`, `genesisConcept.js`, `genesis.js`, `officers.js`.

---

## Онбординг

Три режима, все сходятся в заморозку концепта:

| Режим | Как |
|-------|-----|
| `quick` | Система семплит оси, игрок правит имя |
| `brief` | Игрок текстом; оси извлекаются (`dossier` сводится сюда) |
| `questions` | По одной оси + уникальная черта (`axisInterview`) |

Игрок утверждает имя города (уникальность — тул проверки, не список) и имя покровителя. Пока идёт longform, в чат идёт полоска прогресса и тутор из конфига.

## Сборка (`generateDomain`)

Нужен `frozenConcept.status === 'READY'`.

1. Ядро (Claude) — 1–3 попытки.
2. Аспекты пачками по 4 (~18 штук, Claude).
3. Сильные стороны города → раздача 220 очков на 4 стата (границы 35–75).
4. Четыре столпа: характер, затем портреты (фон, не блокируют старт).
5. Бриф города, каталог сущностей (якоря для тайн).
6. Стартовые истории: одна `SITUATION` и одна `EPISODE` (несхожие). Живой посев дальше — [SEED.md](SEED.md).
7. Картина острова (фон).

Имена людей — из `world.namePool` (`config/names.yaml`). Имя города придумывает модель, код отсекает запрещённые.
