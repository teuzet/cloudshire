# Пивот: плотлайны как ядро мира

Статус: **фазы 0–4 сделаны**, остался вопрос режиссёра (фаза 5) и показ статов игроку.
Миграции нет — переход через вайп.

Что уже работает:

| Кусок | Где |
|---|---|
| Модель нити, каст, журнал месяца | `plotlines.js`, `models.js` |
| Броски: ход дел и окраска битов | `rolls.js` |
| Часы, отбор битов, ворота журнала, бюджеты | `plotEngine.js` |
| Четыре сцены рассказчика | `storyteller.js` |
| Месяц города целиком на нитях | `monthResolve.js` |
| Тик: соло и стык на одних рельсах | `tick.js` |

Удалены: агент `resolver`, агент `director` вместе с `director.js`, парный резолвер
`confluxResolve.js` и временный слой совместимости в `plotlines.js`. Агент `confluxResolver`
остался только для контакта и расстыковки (их пишет `conflux.js`).

Режиссёр как агент не понадобился: отбор битов, завязки и закрытия считает движок.
Решение по фазе 5 — оставить так.

## 1. Главный сдвиг

Раньше события месяца сочинял один большой резолвер, а плотлайны были комментарием к готовой
хронике. Теперь наоборот: **в мире не бывает событий вне нитей**. Дело, указ, находка, тихий
месяц — это биты нитей или их осознанное отсутствие.

Резолвер и conflux-резолвер удаляются. Их работу делят четыре маленькие сцены одного рассказчика.

## 2. Инварианты

1. **Движок считает, агент говорит.** Всё исчислимое — ход дел, броски, величины дельт, бюджеты,
   жребий тегов, отбор битов — в коде. Агент получает готовый факт и облекает его в язык.
2. **Сила влияния регулируется наличием в контексте, а не формулировкой.** «Если уместно» модель
   читает как «используй». Ослабить влияние = не класть в промпт. Настраиваемость = ворота с числом
   в конфиге.
3. **Всё принадлежит домену.** Ни одна сущность не висит на конфлюксе или на мире.
4. **Одна запись — один факт.** Хроника сухая и предметная; чувство живёт в письме правителя.
5. **Каждая цифра имеет причину.** Игрок видит статы числами, поэтому любое изменение привязано
   к записи хроники, которая его объясняет.
6. **День принадлежит правителю, месяц — миру.** Мгновенная сцена рассказывается сразу и является
   каноном; системные последствия приходят с тиком.

## 3. Модель данных

### 3.1 Плотлайн

```
{
  id, title,                    // константы после завязки
  synopsis,                     // текущее положение дел, переписывается на бите
  tags: [],                     // жребий движка при завязке
  relatedStats: [],             // что сейчас в игре; пересматривается на каждом бите
  chronicleIds: [],             // все записи нити
  closeWhen,                    // условие финала
  relatedProcessIds: [],
  importance,                   // 0–100, задаёт масштаб дельт
  maxAgeMonths, ageMonths,
  temperature,                  // 0–100
  kind: 'story' | 'errand',     // errand = проходная нить дела
  mirrorOf, confluxId, partnerGone,   // зеркала на стыке
  status, createdTick, lastBeatTick
}
```

Удалено из старой модели: `attention`, `openHook`, `breakthroughThisTick`, `lastBreakthroughTick`,
`summary` (переименован в `synopsis`), `relatedPendingIds` (переименован в `relatedProcessIds`).
Прорыв больше не отдельная механика — это обычный бит.

### 3.2 Персонаж

Третий тип записи в `domain.lore` рядом с `chronicle` и `fact`:

```
{ id, tags: ['character'], name, role, about,
  firstSeenTick, relatedPlotlineIds: [], status: 'alive'|'dead'|'gone' }
```

Заводят: `storyteller` при бите (поле `newCharacters`) и `loremaster`, когда отвечает про человека.
Каст — рабочий узел, а не украшение: найденный в разговоре кузнец и погибший в сюжете кузнец —
одна запись.

### 3.3 Журнал месяца

`domain.state.monthLog: [{ tick, at, text }]` — короткие пометки из `dayNote` реплик правителя.
Пишется только когда в мире что-то произошло: появился человек, отдан приказ, кто-то отказался.
На вопросы и болтовню — пусто. Очищается после тика.

### 3.4 Конфиг

Секция `tick.plot`:

- `board`: `maxOpen` (5), `maxErrands` (2)
- `beats`: `maxPerTick` (3, обязательные пробивают), `baseChance`, вклад температуры, важности,
  возраста
- `roll`: границы сжатой шкалы (удача от ~25% до ~75%), перевес главного стата, полосы окраски
- `stats`: `playerBudget`, `worldBudget` (месячные потолки движения), масштаб от важности,
  множитель финала, правила катастрофы
- `log`: `influenceChance` (ворота журнала)
- `tagGroups`: существующие семь + `tone` (тон истории) + `start_event` (стартовое событие)

## 4. Агенты

| Было | Стало |
|---|---|
| `resolver`, `confluxResolver` | удалены |
| — | **`storyteller`**: `plot_seed`, `plot_beat`, `decision_echo`, `quiet_month` |
| `director` | тонкий агент или код — решаем в фазе 5 |
| `ruler`, `tickNews`, `loremaster`, `genesis`, `onboarding` | состав без изменений |

### 4.1 Контракты сцен

**`plot_seed`** ← два-три тега жребия (повод + ставка, иногда угол зрения), описание города, каст,
последние записи хроники, дела в работе и крайние статы.
→ `title`, `synopsis` (кто чего хочет, что мешает, чем грозит), `closeWhen`, `importance`,
`maxAgeMonths`, `relatedStats`, `entry` (запись хроники), `newCharacters[]`.
Требование: зацепиться за уже существующего человека, место или дело — история ниоткуда запрещена,
но и клон идущей нити тоже: у новой истории свой предмет, своё место и свои люди.
Жребий можно взять частично, если иначе выходит нелепица. Близнеца движок отсеивает сам
(сравнение названия и синопсиса), нить от `decision_echo` в таком случае вливается в существующую.

**`plot_beat`** ← нить, окраска броска (в пользу города / двойственно / против), каст, итоги
связанных дел, при открытых воротах — одна строка журнала.
→ `entry` (запись хроники), `synopsis` (новый), `relatedStats` (новые), `affects[]`
(направление дельт: стат + сторона + грубая сила), `newCharacters[]`, `closes` (финал ли),
`catastrophe` (флаг с обоснованием).
**Финал — не строка о работах:** развязке дают в 1.6 раза больше символов, требуют место,
названных людей и видимый исход (сход, обряд, расчёт, приговор) и разрешают одну фразу о том,
что теперь в городе иначе.

**`decision_echo`** ← указы месяца (все сразу), состояние.
→ одна `entry`, `affectedStats[]`, `affects[]`, при нужде завязка нити
(`becomesThread` + `threadTitle`/`threadSynopsis`/`threadCloseWhen`; близнец существующей
нити не заводится, а вливается в неё).

**`quiet_month`** ← описание города, сезон, каст, последние записи и жребий движка:
тема (о чём), фокус (через кого), форма случая (мелкая удача / потеря / ровный быт)
и дрифт (какая сторона города чуть окрепла или просела).
→ одна сухая `entry` + `newCharacters[]`. Величину дрифта считает движок (±1…2 из бюджета мира),
направление тянется к середине: просевшее чаще выправляется, раздутое чаще садится.

### 4.2 Правитель

В `submit_reply` добавляются два поля:

- `touchedPlotIds[]` — какие нити задел покровитель; идёт в температуру **числом**
- `dayNote` — одна фраза о том, что произошло сегодня в мире (или пусто)

## 5. Анатомия тика

1. Дата, счётчики конфлюкса.
2. **Ход дел** — движок: застой, рывок, завершение, рядовой ход.
3. **Часы нитей**: возраст, распад температуры, прирост от `touchedPlotIds`.
4. **Отбор битов.** Сначала обязательные: завершилось или сорвалось связанное дело; нить упёрлась
   в `maxAgeMonths` (финальный бит). Затем добровольные по вероятности от температуры, важности
   и возраста — до потолка. Обязательные потолок пробивают.
5. **Окраска добровольных битов**: движок берёт стат из `relatedStats` с перевесом в пользу
   главного, кидает по сжатой шкале, получает исход. Биты от дел наследуют окраску броска дела.
6. **Ворота журнала**: движок решает, будет ли бит отзывчивым; если да — кладёт одну связанную
   строку. Иначе журнала в промпте нет вовсе.
7. **Завязки**: шанс зависит от нехватки живых историй до `board.targetStories`
   (проходные нити дел не в счёт): пустая доска сеет почти наверняка, полная — редко.
8. **Биты**: `plot_beat` на каждую отобранную нить.
9. **Отзвук решений**: все указы месяца — одним `decision_echo`.
10. **Тихий месяц**: если не случилось ничего из 8–9 — `quiet_month`.
11. Применение дельт с бюджетами и клампами, обновление `state`, очистка журнала
    (внутри резолва: снаружи запись поверх устаревшего домена стирает весь месяц).
12. **Пик месяца**: развязка или катастрофа отдаётся письму как главное
    событие — с него письмо и начинается.
13. `tickNews` — письмо; к нему блок статов с изменениями.

## 6. Механика чисел

**Единый модуль бросков** (`src/game/rolls.js`): ход дел, окраска битов, всё будущее. Весь баланс
в одном месте.

**Сжатая шкала.** Вероятность удачи идёт примерно от четверти до трёх четвертей, а не от нуля до
ста: слабость чувствуется, но не приговаривает.

**Дельты — гибрид.** Направление от агента (`affects`), величина от движка. Масштаб задаёт
`importance`: проходной спор — единица или ничего, судьбоносный финал — пять-десять. Промежуточные
биты двигают редко и мелко, финалы весят больше.

**Два бюджета месяца**: решения игрока и события мира считаются раздельно, чтобы ни один не съедал
другой. Внутри игрокского — убывающая отдача: первое решение в полную силу, дальше меньше.

**Восстановление — через выбор события, не тихой коррекцией.** При низком стате чаще выпадают
повороты, дающие городу шанс. Число двигается, но за ним всегда описанный случай: игрок видит
цифры, и невидимая подкрутка читалась бы как жульничество.

**Катастрофа — явный флаг** с обоснованием: бюджет не действует, движок логирует и не даёт
повторить чаще раза в несколько месяцев.

**Доска не пустует, но и не набивается залпом.** `board.targetStories` — сколько живых историй
город хочет держать; каждая недостающая добавляет `seedPerMissing` к шансу завязки, потолок
`seedMaxChance`. Проходная нить от стройки историей не считается. После свежей завязки
`seedCooldownMonths` месяцев не сеем: иначе доска заполняется клонами одного события.

**Целей сезона нет.** Список задач с очками сбивал и рассказчика, и игрока: город живёт своими
историями, а не галочками.

## 7. Что делает реплика игрока

| Реплика | Последствие |
|---|---|
| вопрос, поиск сведений | факт или персонаж в касте; больше ничего |
| болтовня, мелочь | сцена сегодня, иногда персонаж, строка в журнале |
| указ (порядок, запрет, правило) | длящийся модификатор; отзвук на тике; при нужде завязка нити |
| поручение с исходом | процесс со сроком (быстрое — 1 месяц); нить-заглушка (`kind: errand`), если своей нет |

**Разовых деяний нет.** «Отправить людей разобраться», «провести обряд», «вскрыть склады» —
это дело со сроком, а не мгновенный жест: у него есть исход, и город о нём доложит.
Единственное по-настоящему мгновенное — объявление: слово сказано, порядок теперь такой.

Правителю запрещено отвечать «узнаем через месяц» вместо сцены: он рассказывает, что происходит
сегодня, а исход дела приходит с новостями месяца.

## 8. Конфлюкс

Владение доменное, зеркала по ссылке (`mirrorOf`, `confluxId`).

- Зеркало рождается не при стыковке, а когда бит одной стороны реально задевает соседа; у соседа
  нить с меньшей важностью.
- Бит зеркальной пары генерится **один раз** и разносится в обе хроники с правильным `location`
  и `concernsDomainIds`; считается одним битом для каждого города.
- Тайные нити не зеркалятся.
- При расстыковке зеркала получают `partnerGone` и укороченный `maxAgeMonths`: следующий бит либо
  закрывает нить, либо превращает её в местную память.

Секретные нити, неизвестные своему правителю, не заводим: правитель — единственный источник
сведений для игрока, скрытая от него нить не существует для игры.

## 9. Сборка контекста

Отдельный слой с явными правилами — сегодня строки собираются прямо в местах вызова, и настраивать
нечего.

**Правитель**: компактная строка на нить (название, фраза о положении, что в игре — качественно,
есть ли дело). Полный синопсис и записи — через `read_domain_brief`. Механики не видит: ни
температуры, ни важности, ни шансов. Продолжение не сочиняет — нити это правда, которую он знает.

**Лормастер**: та же компактная доска, полная хроника, факты, каст, состояние. Хронику не пишет.

**Storyteller на бите**: своя нить, окраска, каст, итоги связанных дел, при открытых воротах — одна
строка журнала. Не видит доску целиком и своды статов.

## 10. Фазы

**0. Модель.** Новая форма нити, тип `character`, журнал месяца, группы тегов и параметры в конфиге.
Вайп локальной базы.

**1. Движок.** Часы нитей, температура из `touchedPlotIds`, отбор битов, окраска, бюджеты дельт,
ворота журнала, единый модуль бросков, нить-заглушка при `declare_process`. Проверяется смоуком
почти без LLM.

**2. Рассказчик: seed и beat.** Две сцены, узкий контекст, сухой стиль. Резолвер пока жив для дел
и указов.

**3. Распил резолвера.** `decision_echo` и `quiet_month`; побочные события как микро-нити; удаление
`resolver` и `confluxResolver`; стык на тех же рельсах.

**4. Персонажи и показ статов.** Каст в контексты и админку; блок чисел с изменениями и причинами
в письме месяца.

**5. Режиссёр.** По данным решаем: тонкий агент или код.

## 11. Метрики

В `npm run report`: битов за тик и доля обязательных; средняя жизнь нити и распределение причин
закрытия; доля месяцев с филлером; распределение окраски по городам и статам; доля битов,
опиравшихся на журнал; месячный дрейф каждого стата; размер каста; цена по сценам.
