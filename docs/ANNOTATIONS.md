# Пулы аннотаций

Живой посев городской истории — не генерация сюжета с нуля на тике, а **карточка из пула** + привязка к городу.

Код: `annotationPool.js`, `annotationCatalog.js`, `annotationSelector.js`, `mysteryAnnotation.js`, `suspenseAnnotation.js`, `plotlines.js` (жребий осей и промпт).

---

## Два пула

- Тайна: стартер `config/mystery-annotation-pool.json`, каталог `annotation_catalog` / `data/annotation-catalog.yaml`.
- Саспенс: то же с `suspense-*`.

Новый мир склеивает стартер + каталог (`attachStoryPoolsFromCatalog`). Каталог **не удаляется при wipe мира**.

## Как берётся карточка

1. Шортлист ~10 из пула для **этого** города: не использованы в его `mysteryClimate` / `suspenseClimate`.
2. Если неиспользованных меньше четырёх — снова весь пул (повтор в том же городе возможен).
3. Селектор (luna) утверждает id.
4. Посев пишет на нить `annotationId` и в климат города.

Карточка **не изымается из мирового пула**. Соседний город может взять ту же.

Отвергнутые из шортлиста не «потрачены».

## Досев

`refillAnnotationPool` сравнивает размер **долговечного** каталога (стартер + каталог) с `poolMin` (в YAML сейчас 10). Карточки из пула не удаляются, поэтому после наполнения досев почти всегда `skipped: pool_ok`.

Вызов — из посева при `!opening` (тиковая завязка, не генезис). Пачка `refillBatch` (3), не добивка до минимума за раз. Фабрика: Claude + luna-судья.

Офлайн: `npm run seed-annotations`, `npm run seed-suspense-annotations`.

## Климат

На домене: какие арены/оси недавно сеялись. Шортлист сортируется новизной; это не глобальный кулдаун.
