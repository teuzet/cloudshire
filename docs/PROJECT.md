# Cloudshire

Текстовая мультиплеерная god-sim для Telegram. Игрок — бог-покровитель летающего острова; говорит не городу напрямую, а **верховному жрецу**. Мир русский, low-magic, прединдустриальный.

Этот документ — текущий продукт. Как устроен процесс и модули: [ARCHITECTURE.md](ARCHITECTURE.md).

---

## Роль игрока

- Один домен на сезон (сейчас: один мир, один город на игрока).
- UX — диалог со жрецом. Команд бота почти нет: `/city` открывает мини-аппку.
- До старта — онбординг (быстрый / бриф / вопросы по осям) → концепт города → длинная генерация.
- В игре жрец принимает волю, заводит **дела** и **указы**, иногда сам пишет **письмо месяца**.
- Игрок называет себя (имя покровителя); жрец — из пула имён мира.

## Домен

Город-государство на изолированном острове. Кроме города на острове ничего нет.

| Слой | Смысл |
|------|--------|
| Статы | Четыре числа 0–100: благосостояние, безопасность, знание, влияние. Бюджет генезиса 220. |
| Вера | `state.faith` — среднее четырёх статов, не пятый стат и не слот дела. |
| Столпы | Казначей, воевода, хранитель, канцлер. Слот длительного дела = свободный столп. |
| Нити | Истории (`mystery` / `suspense`), поручения, указы. Событий вне нитей нет. |
| Дела | Процессы на столпе: срок, бросок хода, финиш. |
| Хроника | Сухие факты месяца. Письмо жреца — отдельный канал. |
| Люди | Записи в лоре; имена из мирового пула, не выдумка агента. |

Жрец (персонаж-связной) хранит лояльность и ужас к покровителю, записную книжку и расписание писем.

## Время

- 1 тик = 1 игровой месяц. 12 тиков = год ≈ 1 реальные сутки (тик каждые 2 часа, границы по часам сервера).
- Между тиками время застыло: диалог, заявки дел и указов.
- На тике код считает броски, часы нитей и очередь дел; модели пишут хронику и письмо.

## Истории

Городская завязка — монетка 50/50 **тайна** или **саспенс**. Карточка берётся из пула аннотаций (не изымается у других городов; климат — на домен). Подробности: [PLOTS.md](PLOTS.md), [ANNOTATIONS.md](ANNOTATIONS.md).

Дело, привязанное к живой истории, двигает её акты. Несколько дел на одной нити стоят в очереди. `UNRELATED` снимается на отдельное поручение.

## Сопряжение

Иногда два острова сближаются и стыкуются на несколько месяцев. Общая доска нитей, информатор, раздельные летописи. См. [CONFLUX.md](CONFLUX.md).

## Клиенты

| Канал | Роль |
|--------|------|
| Telegram | Основной чат + mini-app «Город» |
| `/play` | Локальный чат и инспектор (вкл. `WEB_PLAY`) |
| `/admin` | Все домены, force tick, wipe |
| CLI | `status`, `tick`, `wipe`, `chat`, `playtest` |

## Хранение

Локально YAML в `data/`. Прод — Mongo. Каталоги аннотаций переживают wipe мира; стартеры лежат в `config/*-annotation-pool.json`.

## Чего в коде нет

- Win/lose сезона.
- Бросок конфликта «наш стат против соседского» на общей нити.
- Мета-валюта, магазин, векторный поиск по лору.
