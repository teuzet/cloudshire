# Заготовки про сопряжение

Здесь лежат истории, которые держатся на сопряжении: оно идёт сейчас, только что кончилось,
к нему готовятся или его предсказывают. В одиночной игре их нет: сопряжение — отдельный
мультиплеерный режим с другим городом (решение Ника 2026-11-16). Загрузчик читает только
`scenarios/*.yaml`, эта папка не загружается. Отсюда потом соберутся группы «во время
сопряжения», «последствия» и «подготовка».
